# 社区行为准则

## 我们的承诺

我们致力于营造一个开放、友好的社区。无论年龄、体型、残疾、种族、性别认同与表达、经验水平、国籍、个人外表、种族、宗教或性取向，每个人都应获得无骚扰的参与体验。

## 我们的标准

**积极行为的示例：**

- 对其他参与者表示同理与善意
- 尊重不同的观点和经验
- 优雅地给予和接受建设性反馈
- 关注对整个社区最有利的结果

**不可接受的行为的示例：**

- 使用性暗示语言或图像，以及任何形式的性骚扰
- 挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可，公开他人私人信息（如物理或电子地址）

## 执行

项目维护者有责任澄清可接受行为标准，并将对不当行为采取适当的纠正措施。

维护者有权利和责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、问题和其他贡献，并可暂时或永久禁止任何贡献者的行为若其认为不当、威胁、冒犯或有害。
