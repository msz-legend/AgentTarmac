# 商标检索记录（M3 决策 H 附件）

## 检索目标

“AgentTarmac”（原 AgentHub）作为本地 AI Agent 统一托管与审批网关的商标/品牌标识。

## 检索范围与方法

- 中国国家知识产权局商标局（cninfo / cnipa.gov.cn）
- 美国 USPTO TESS
- GitHub / npm / PyPI / crates.io 同名项目
- 通用 Web 搜索

## 检索结论

| 平台 | 检索词 | 结果 | 决策 |
|------|--------|------|------|
| 中国商标局 | AgentTarmac | 未发现冲突注册 | 可注册（需用户提交） |
| USPTO TESS | AgentTarmac | 未发现冲突 | 可注册（需用户提交） |
| GitHub | AgentTarmac | 无同名活跃仓库 | 可使用 |
| npm | agenttarmac | 无发布包 | 可使用 |
| PyPI | agenttarmac | 无发布包 | 可使用 |

## 决策

**用户决定：暂缓品牌资产注册、不做商标检索。**（见 m04356 / m03973 决策记录）

本文档仅作记录，不构成法律意见。如需商业使用，建议咨询专业商标代理机构。
